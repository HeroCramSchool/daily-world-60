# BGM プール

ここに `.mp3` / `.m4a` / `.wav` / `.ogg` を置くと、build-news-video が
**動画ごとに自動でローテーション**します（日付+国コード+index の決定的ハッシュで選択）。

- ファイルが 0 個 → `assets/news-bed.mp3` を使用（曲は同じでも**開始位置は動画ごとに変わる**）
- ファイルが複数 → 曲そのものもローテ

## なぜ必要か（2026-08 調査）

YouTube のスパムポリシーは AI 量産チャンネルの例として
「多くの動画で**まったく同じBGM**と繰り返しの AI 生成画像を使い、AI 生成スクリプトを読み上げる」
を名指ししている。これはチャンネル削除（3ストライク/90日）の経路であり、収益化剥奪より重い。
曲の使い回しを避けることが直接の対策になる。

## 追加時の注意

- **YouTube オーディオ ライブラリ**の曲が最も安全（Content ID クレームが起きない）
- Pixabay 等の CC0 も可だが、一部は Content ID に登録されており**クレームが発生しうる**
- **60秒を超える Short に Content ID クレームが付くと全世界でブロック**されるため、
  出力尺は 59 秒以内に収める運用と併せて守ること
